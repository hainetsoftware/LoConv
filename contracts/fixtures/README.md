# Synthetic wire fixtures

All names, IDs, sizes, durations and codec facts here are invented, not extracted
from any media. The large sizeBytes value intentionally exceeds JavaScript's
safe integer range. Format availability is hypothetical for UI mocks, not
detected capability. These JSON files are shared contract examples, not a
production registry. Rust round-trips them; the frontend task must consume the
same files with runtime validation and compile-time conformance tests.
